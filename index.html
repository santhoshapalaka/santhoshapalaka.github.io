On 17th September 2026, during Srimatsaram Kalakshepam (Niryanadhikaram), Lakshmi Narasimhan Swami (alias 'CP') asked how Jatayu attained Moksham despite having neither done Bhakti nor Prapatti. Sri APN Swamin concluded his elaborate answer, by saying that (we) should create a page for each character (e.g. Jatayu) and note down such points over there, so that it'd be easily fetchable when the need arises. santhoshapalaka.github.io was created to serve this purpose on Radhasthami (19th September 2026); it is a Character Reference Library based on Sri APN Swami's teachings.
